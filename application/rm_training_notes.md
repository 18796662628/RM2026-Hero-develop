# RM电控培训作业说明

本文档对应当前单板整车控制实现。作业范围只包含云台 Yaw/Pitch 和四个麦克纳姆底盘轮；发射、摩擦轮、DM4310、推杆、履带、裁判系统、视觉及超级电容均不参与本次控制。

## 1. 单板拓扑

| 总线 | 电机 | 拨码 ID | 控制帧 | 反馈帧 |
| --- | --- | ---: | ---: | ---: |
| CAN1（经过滑环到底盘） | Yaw GM6020 | 1 | `0x1FE` | `0x205` |
| CAN1（经过滑环到底盘） | 左前、右前、右后、左后 M3508 | 1, 2, 3, 4 | `0x200` | `0x201` 到 `0x204` |
| CAN2（炮管上层） | Pitch GM6020 | 2 | `0x1FE` | `0x206` |

同一条 CAN 上，GM6020 和 M3508 的拨码 ID 可以都为 1，因为两类电机的反馈 CAN ID 计算不同。M3508 的反馈 ID 为 `0x200 + ID`；GM6020 的反馈 ID 为 `0x204 + ID`。

`RobotInit()` 只调用 `RobotCMDInit()`、`GimbalInit()` 和 `ChassisInit()`。所以当前单板运行时只会注册两台云台电机和四个底盘轮。

## 2. 任务与消息流

所有核心任务以约 1 kHz 运行：

```text
遥控器 USART3
    -> RobotCMDTask
    -> gimbal_cmd / chassis_cmd 主题
    -> GimbalTask / ChassisTask
    -> DJIMotorControl
    -> CAN 控制帧
```

`RobotCMDTask` 是唯一的遥控器解释位置。它把遥控器输入转换为标准控制命令；云台和底盘应用只订阅各自的命令主题。这样的发布-订阅结构避免云台和底盘相互直接依赖。

## 3. 安全状态机

安全状态由 `RobotCMDTask` 维护，优先级高于所有运动命令：

```text
遥控器离线、开关非法、左右拨杆同时向下
    -> ESTOP：所有电机零输出

ESTOP 后将两个拨杆同时保持在中间约 0.5 秒
    -> ARMED：允许云台和底盘接收命令
```

遥控器失联时同样进入急停。云台任一电机反馈离线，或四个底盘轮中任意一个反馈离线，也会阻止对应电机输出。

## 4. 遥控器映射

| 输入 | 功能 |
| --- | --- |
| 左摇杆水平 | Yaw 连续角速度指令 |
| 左摇杆竖直 | Pitch 角速度指令 |
| 右摇杆竖直 | 底盘前后速度 `vx` |
| 右摇杆水平 | 底盘横移速度 `vy` |
| 侧边拨轮 | 普通模式下的手动旋转 `wz` |
| 右上三档拨杆居中 | 普通全向模式 |
| 右上三档拨杆向上 | 正向自动旋转模式 |
| 右上三档拨杆向下 | 反向自动旋转模式；左右拨杆同时向下仍是急停 |

若实际机械方向与表意相反，只调整对应方向宏或轮子反向标志，不改运动学公式。

## 5. 云台控制原理

BMI088 随云台一起转动，因此 Yaw 和 Pitch 都使用 IMU 角度、角速度作为反馈。每个轴是串级 PID：

```text
摇杆 -> 目标角速度 -> 积分得到目标角度
目标角度 - IMU角度 -> 角度环 -> 目标角速度
目标角速度 - IMU角速度 -> 速度环 -> 电机电流指令
```

Yaw 摇杆输入经过死区、低通与加速度限幅后再积分。这样松开摇杆时，目标角度停在当前位置，云台仍能保持姿态。Pitch 也以角速度积分方式生成目标角度。

Pitch 软限位以解锁时确认过的中位姿态为基准：负方向 12 度、正方向 40 度。每次解锁前应先把炮管置于这个中位姿态。

## 6. 麦克纳姆底盘解算

底盘接收 `vx`、`vy`、`wz` 后，计算四个轮子的速度参考值：

```text
LF = -vx - vy + wz * LF_CENTER
RF = -vx + vy - wz * RF_CENTER
LB = -vx + vy + wz * LB_CENTER
RB = -vx - vy - wz * RB_CENTER
```

其中 `LF_CENTER` 等参数由轴距、轮距和云台相对底盘中心的偏移决定。每个轮子各自做速度闭环，输出电流指令；四轮同时叠加正确的正负号，就能实现前后、横移、斜移和原地旋转。

## 7. 后续 MATLAB 调参

底盘旋转时若 Yaw 抖动，不要先凭感觉继续调 PID。建议记录并绘制以下同一时间轴的数据：

1. `YawTotalAngle` 与 Yaw 目标角度。
2. Yaw 陀螺仪角速度与角度环输出的目标角速度。
3. Yaw 速度环输出电流。
4. 底盘 `wz`、四轮速度参考与四轮实际速度。

先固定底盘，再调 Yaw 速度环：观察角速度阶跃时的超调、收敛时间与高频噪声。再让底盘匀速旋转，观察 Yaw 跟随误差是否随底盘旋转速度增大。如果角速度噪声在电机不动时已经很大，应优先检查 IMU 安装、线缆拉扯和机械间隙；如果噪声主要在旋转时出现，再检查底盘振动和 CAN 报文延迟。

## 8. 答辩重点

1. 为什么单板后需要重新规划 CAN 发送分组和应用初始化。
2. 为什么急停必须在遥控器解析后、所有运动命令前执行。
3. 为什么云台使用 IMU 闭环，而不是只用电机编码器。
4. 为什么摇杆先转换成角速度，再积分成目标角度。
5. 麦克纳姆四轮速度符号如何产生全向移动和旋转。
